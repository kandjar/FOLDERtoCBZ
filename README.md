# FOLDERtoCBZ
Create CBZ from FOLDER

## Requierements
 - 7-Zip (https://www.7-zip.org/download.html). 
 - Verify the path of where 7z.exe is installed (c:\Program Files\7-Zip) in the bat script
 - Create 3 folders (folder, folder done, cbz)
 
## Folder structure

- MainFolder
   - FOLDERtoCBZ.bat
   - folder

	   - SubF02
		  - img001.jpg
		  - img002.jpg
		  - img003.jpg

   - folder done
   - cbz
   
## Process :
 - Place your volume folders in the folder directory
 - Execute the bat
 - The cbz files are in the cbz folder
